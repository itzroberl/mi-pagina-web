# Email template field notes

- Accounts: created a new free Vercel/v0 team (`larezroberto58-8325`) and a new Nitrosend account for this test (account 14108, brand 14320). The Nitrosend account had not previously sent through its MCP connection.
- Design: liked and opened the [Nitrosend email template gallery item](https://v0.app/templates/nitrosend-email-marketing-templates-X6Lmfdz3Jq3) in the new v0 team. The imported v0 chat remained private; it was not deployed or published.
- Template: customized Nitrosend Original's **The Welcome Note** in Nitrosend and saved it as template **26541**. I replaced the generic body with Spanish welcome copy, added the public PatchProof Works avatar, changed the CTA to **Ver proyectos** linking to the public GitHub project, and used teal `#0f766e` for the button and brand color.
- Sender: configured the hosted sender `hello@patchproof-works.nitrosend.net` for the PatchProof Works brand. This did not require control of a separate DNS domain.
- MCP client: Codex CLI **0.166.0-alpha.5.1**, model **gpt-6-luna**, using Nitrosend's OAuth MCP. I checked account and sender readiness, then made one individual `nitro_send_message` call using `channel=email`, `template_id=26541`, an explicit subject, and an idempotency key. The API returned message **5335028** as `queued`; Nitrosend then sent a signed receipt saying the message reached its proof inbox at **2026-11-04 03:01 UTC**. The receipt URL is intentionally not reproduced in this public report.
- Elapsed time: approximately **39 minutes** from claiming the work to receiving the signed receipt. The slowest step was new-account onboarding and completing the private v0 import, including Vercel verification.
- Improvement: an MCP preflight showing whether the hosted sender and template subject are ready before the first send would reduce back-and-forth between the brand setup UI and MCP client. In particular, the test-send route did not expose a subject override, so I used the single-recipient send route with the saved template and an explicit subject.
